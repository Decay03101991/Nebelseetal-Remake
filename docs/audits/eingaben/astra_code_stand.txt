STAND DES CODES — Nebelseetal Remake, 04.10.2026. Ehrliche Selbstdarstellung, absichtlich ohne
Beschönigung. Grundlage ist der tatsächliche Code (src/main.py, src/kampf.py, src/einheiten.py,
src/spieldaten.py, src/bonus_system.py) und die Datendateien unter data/.
Bei jedem Punkt steht: umgesetzt / teilweise / fehlt.

== Siedlungen ==
- Anzahl: der Code erlaubt 3 Siedlungen (in _found_settlement geprueft). Handbuch: bis 6. -> ABWEICHUNG
- Siedeln: _found_settlement legt eine Siedlung auf der aktuellen Karte an. Der Siedlerkarren
  (Ladung) wird nicht verbraucht, es gibt keine Kostenpruefung fuer das Siedeln. -> TEILWEISE
- Gelände: eine Siedlung hat KEIN Gelände. Das Handbuch laesst Gebäude nur auf bestimmten
  Geländearten zu (Bibliothek nur Grasland/Steppe/Nebelsee; Sümpfe unbebaubar). -> FEHLT
- Lager, Umbenennen, Siedlung aufgeben: Lageransicht vorhanden; Umbenennen vorhanden (last_rename);
  Siedlung aufgeben: -> FEHLT

== Gebäude ==
- 10 Gebäude im Code (erfunden: holzfäller, steinmetz, jäger, haus, schmiede, bibliothek, markt,
  kaserne, turm, portal). Handbuch: 20 Gebäude. -> ABWEICHUNG
- Baupreise: erfundene Zahlen, nur die Rohstoffnamen sind original. Das Handbuch nennt KEINE Preise.
- Ertrag: feste Zahlen je Gebäude im Code (prod_map). Handbuch: Ertrag je GELAENDEART
  (Beispiel Holzfäller: Wald 4/h, Steppe 2/h). -> ABWEICHUNG
- Ausbau: Stufe +1, Kosten steigen linear mit (level+1). Handbuch: "Der Ausbau wird mit jeder
  Stufe teurer" (ohne Zahlen). -> TEILWEISE
- Verteidigungswall mit 10 Stufen und Schwellenwerten: Daten liegen vor (data/buildings.json),
  im Spiel ist der Wall aber nur ein Turm mit level. -> TEILWEISE

## 1. Einheiten — **28 Stück**, vier Typen

Das Handbuch nennt wörtlich **vier Einheitentypen**: „Die Karren, die Belagerungswaffen, die
Kundschafter und die Kampfeinheiten." Ausbildungsgebäude:

| Typ | Gebäude |
|---|---|
| Karren und Belagerungswaffen | **Stellmacher** (Originalschreibweise, 4× belegt — *nicht* „Stallmacher") |
| Kundschafter | Diebesgilde |
| Kampfeinheiten (Armee) | Kriegerakademie |

Je Siedlung höchstens eines dieser Gebäude; höhere Stufe = schnellere Ausbildung.
Ausbildung läuft laut Handbuch über „Auftrag erteilen" in eine **Warteschlange**, nacheinander
abgearbeitet.

## 2. Werte einer Einheit (Original-Abkürzungen, Handbuch Seite 17)

| Kürzel | Bedeutung |
|---|---|
| LE | Lebensenergie — je höher, desto mehr Schaden wird verkraftet |
| AT | Angriffswert — Trefferchance |
| PA | Paradewert — Chance, eine gegnerische Attacke abzuwehren |
| SI | Sinnesschärfe — Spione entdecken (Handbuch: „hat im Moment noch keinen Einfluss") |
| HE | Heimlichkeit — unauffälliges Verhalten (Handbuch: noch ohne Einfluss) |
| RS | Rüstungsschutz — senkt den erlittenen Schaden |
| TP | Trefferpunkte — Schaden pro Treffer, als Bereich (z. B. 2-13) |
| GS | Geschwindigkeit — Reisegeschwindigkeit |
| MU | Mut — Kampfentschlossenheit und Fluchtwahrscheinlichkeit |
| SK | **Schlagkraft** — nötig, um die Verteidigung zu durchbrechen |

**Die Zahlenwerte sind bewusst nicht als Tabelle eingetragen.** Die automatische PDF-Auslesung
liefert die Zahlenreihen, aber die Spalten laufen ineinander (Kopfzeile „LE AT PA SI HE RS TP GS MU SK",
Zeilen teils mit 8 statt 10 Werten). Eine falsche Zuordnung wäre schlimmer als keine. Rohwerte:
`Spielanleitung_2009_Textfassung.txt`, Seiten 15–17. Nächster Schritt: an der gedruckten Seite
ablesen und spaltensicher übernehmen.

Einzelwerte, die wörtlich belegt sind: Katapult **Schaden 2-13**; Palisade Ausbaustufe 4 → 64 Kriegspunkte.

## 4. Rohstoffe — 9 Stück (Handbuch Seite 9/10)

| Gebäude | Rohstoff | Produktion/Stunde |
|---|---|---|
| Holzfäller | Holz | Wald 4, Steppe 2 |
| Steinmetz | Stein | Berg 4, Hügel 2 |
| Erzmine | Metall | Berg 3, Hügel 1,5 |
| Tempel | Mana | Nebelsee 5, alles außer Sumpf 1 |
| Farm | Nahrung | Grasland 4, Steppe 2 |
| Goldmine | Gold | Berg 3, Hügel 1,5 |
| Schafszucht | Wolle | Grasland 3, Steppe 1,5 |
| Rinderfarm | Leder | Grasland 3 + 3, Steppe 1,5 + 1,5 |
| Pferdezucht | Pferde | Grasland 3, Steppe 1,5 |
| Jäger | Nahrung + Leder | Wald 2 + 2, Steppe 1 + 1 |

- Sümpfe sind **unbebaubar**.
- Der **Rohstoffzuwachs pro Stunde** steht im Spiel in Klammern hinter dem Bestand; ein **Balken**
  zeigt, wann die nächste Einheit dazukommt.
- **Siedler:** 1 pro Stunde bis zur Grenze. Grenze laut Handbuch **10 je Siedlung**, **+5 pro Haus**
  (die 2005er Fassung nannte 5 — Versionsunterschied).
- **Startwerte:** 10 Siedler, 100 Holz, 100 Steine. Maximal **6 Siedlungen**; die Karte wird zufällig
  zugewiesen, nie zweimal dieselbe gleichzeitig.
- Bibliothek nur auf Grasland, Steppe oder Nebelsee, **eine je Siedlung**.
- Bauen: Holzfäller, Steinmetze, Jäger, Bibliothek und Häuser sind **ohne Forschung** möglich,
  alles Weitere braucht **Baukunst**. Gebäude werden auf der **Siedlungskarte** platziert; der
  Mauszeiger zeigt die Eignung des Feldes an. Ein Abriss bringt **keine** Rohstoffe zurück.

**Forschungsregeln (Handbuch Seite 11/12):**
- Dauer = **neue Stufe² Stunden** (Beispiel: Baukunst 2 → 3 dauert 9 Stunden).
- Ressourcenkosten **verdoppeln sich je Stufe** (50 → 100 → 200 → 400).
- Während der Studien ist der Forschungsbereich der Siedlung **blockiert**.
- Die Stufe steigt **erst nach Ablauf**, nicht beim Start.
- **Abbruch** kostet Zeit **und** Ressourcen ersatzlos.

## 7. Was das für den Code bedeutet

| im Code heute | Original |
|---|---|
| 36 Einheiten mit erfundenen Namen (Worg, Hexe, Drache, Troll, Ork, Golem …) | **28 Einheiten**, Namen siehe Abschnitt 1 |
| Rohstoffe `kristall, eisen, stoff, geld, wissen` | **Mana, Metall, Wolle, Pferde** — kein Kristall, kein „Geld" als Rohstoff |
| 17 Waren nur als Emoji-Einträge | **17 Waren** als gefertigte Ausrüstung mit Werkstatt und Voraussetzung |
| Kampf = ein Zufallsvergleich | **Vorrunde + Kampfsequenzen + Zweikämpfe** (siehe `ORIGINAL_Kampf_und_Punkte.md`) |
| keine Belagerung, keine Karren, kein Ladungssystem | 7 Belagerungswaffen, 6 Karren mit Ladung |
| Punkte = Forschung + Krieg + Truppenzahl | Forschungspunkte = Σ Stufe³, Kriegspunkte je Einheit, Verteidigungsanlagen³, Gesamt = (Krieg + Forschung) / 2 |

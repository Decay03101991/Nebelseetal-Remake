# Nebelseetal ausprobieren (experimentell)

**Noch kein stabiler Release** und keine verifizierte Windows-EXE.

Unter Windows Python 3 mit Tkinter installieren. Projekt separat entpacken und `START_SPIEL_WINDOWS.bat` aus dem Hauptordner starten. Jeder Nutzer richtet beim ersten Start ein eigenes lokales Passwort ein. Die Testspielstaende werden separat unter `%LOCALAPPDATA%\Nebelseetal_Remake\KONSOLIDIERT_20261028` gehalten.

Nur die aktive Fassung aus `src/main.py` testen, keine alten Builds aus `archiv/`. Funktionen wie Bot-Wirtschaft, Belagerung, Teile des GUI und die Windows-Buildabnahme sind noch nicht fertig. Fehler ueber GitHub Issues melden.

Projekt: https://github.com/Decay03101991/Nebelseetal-Remake

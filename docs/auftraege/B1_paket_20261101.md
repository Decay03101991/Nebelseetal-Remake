## 5 Was das Werkzeug messen MUSS

Jede Kennzahl mit **einer gedruckten Zeile**: Kennzahl, Wert, Quelle (Datei:Zeile oder Datenfeld).

1. **Erträge je Gebäude und Gelände** - gelesen aus `data/buildings.json` (`ertrag_pro_stunde`), gegengehalten gegen die Handbuchtafel (Abschnitt 6 unten). Auch die Gebäude **ohne** Ertrag (Werkstätten, Ausbildungsstätten, Wall, Bibliothek, Haus, Dorfzentrum) sind zu nennen, mit dem Vermerk „kein Ertrag“.
2. **Reichsertrag je Spielstunde und je Spieltag** aus einer **nachvollziehbaren Beispielbelegung**: ein Dorf mit 10x10 Feldern, je Feld ein Gebäude, Geländeverteilung aus `data/gelaende.json` (Gewichte) - und zusätzlich der Fall „bester Fall“ (jedes Gebäude auf seinem besten Gelände) und „schlechtester Fall“ (nur zweitbestes Gelände). Rechne die drei Fälle als Spannweite, nicht als eine Zahl.
3. **Siedlerzuwachs und Siedlerdecke**: 1 Siedler/Stunde je Siedlung, Grenze 10 + 5 je Haus, sechs Dörfer. Nutze die vorhandene Rechenstelle (`gebaeude_wirkung.siedlergrenze_je_siedlung`, `bevoelkerungsgrenze`, `siedler_zuwachs_pro_stunde`), nicht eine eigene Formel.
4. **Goldfluss je Spieltag**: aus Goldmine (Berg/Hügel) - und was dagegen an Gold abfließt, soweit es aus Daten belegbar ist (Reisekosten, Baukosten in Gold). Wenn nichts belegbar ist: „nicht belegbar“ schreiben, nicht raten.
5. **Mana je Spielstunde**: Tempel auf Nebelsee 5, sonst 1, auf Sumpf 0, Götterkunde +5 % je Stufe (so steht es im Register, siehe Abschnitt 6). Rechne die Varianten einzeln.
6. **Nahrungsverbrauch**: 8 je Einheit und Spieltag (laufend), Reisekosten je Feld getrennt; nutze `spieloekonomie.tagesbedarf_nahrung` und `verbrauch_pro_stunde`.
7. **Waren- und Ausbildungsdauern**: Dauer je Ware aus den Rezeptdaten, Dauer je Einheit aus `spieloekonomie.ausbildung_start` (Grunddauer geteilt durch Stufenfaktor), Warteschlangen-Effekt bei mehreren Werkstätten.
8. **Verhältniskennzahlen** (daraus entsteht der Balance-Wert): Ertrag je Siedler, Siedler je Gebäude, Zeit bis zur ersten Siedlung, Zeit bis 100 Einheiten, Verbrauchsanteil der Nahrung am Tagesertrag bei 100 und bei 360 Einheiten.

```python
def tagesbedarf_nahrung(einheiten, aktiv: bool | None = None) -> float:
    """Nahrungsbedarf einer Einheitengruppe je SPIELTAG (VORSCHLAG, `data/nahrungsverbrauch.json`).

    EINE Rechenstelle fuer Kern (``ort_tick``) und Anzeige (Kopfzeile) - sonst entstehen zwei
    Wahrheiten. ``aktiv`` ueberschreibt den Schalter der Datendatei (fuer Pruefungen).
    Gezaehlt wird JEDE Einheit gleich; Karren und Belagerungsgeraete fahren mit, weil sie im
    Ortslager als Einheiten gefuehrt werden (die Datenlage kennt keinen zweiten Zaehler).
    """
    if aktiv is None:
        aktiv = NAHRUNGSVERBRAUCH_AKTIV
    if not aktiv or NAHRUNG_JE_EINHEIT_TAG <= 0:
        return 0.0
    anzahl = 0.0
    for menge in (einheiten or {}).values():
        if isinstance(menge, bool) or not isinstance(menge, (int, float)):
            continue
        if not math.isfinite(float(menge)) or menge <= 0:
            continue
        anzahl += float(menge)
    return anzahl * NAHRUNG_JE_EINHEIT_TAG
```

### Funktion `ort_tick` aus `src/spieloekonomie.py` (Zeilen 1052-1105)
```python
def ort_tick(ort: dict, ab: float, bis: float, forschung: dict) -> dict:
    """Einen Ort von Spielzeit `ab` bis `bis` fortschreiben. Liefert den neuen Ort.

    Produziert über `wirtschaft.ertrag_gesamt` (dieselbe Quelle wie die Anzeige), schreibt
    Siedlerzuwachs bis zur Grenze fort, holt fertige Werkstattwaren ins Lager und bucht
    abgeschlossene Ausbildungen **genau einmal** (`gebucht`). Jede Produktionsspanne landet im
    `produktionsjournal` — Grundlage des Versorgungsfensters (Schritt 7).

    Seit Daniels Entscheidung 7 (31.10.2026) verbraucht die GARNISON laufend Nahrung
    (`tagesbedarf_nahrung`, Betrag VORSCHLAG). Der Verbrauch steht als eigener Posten neben der
    Produktion im Journal - `mengen` bleibt die reine Ernte, damit das Versorgungsfenster
    unveraendert weiterrechnet. Reicht die Nahrung nicht, faellt der Bestand auf 0 und der Rest
    steht als `unterdeckung` im Journal; eine Strafe dafuer gibt es bewusst nicht.
    """
    if bis < ab:
        raise ValueError("Spielzeit darf nicht zurücklaufen.")
    neu = copy.deepcopy(ort)
    ertrag = {k.lower(): v for k, v in wirtschaft.ertrag_gesamt([neu], forschung).items()}
    produktion = {}
    for r, rate in ertrag.items():
        menge = rate * (bis - ab) / 3600.0
        neu["vorraete"][r] = neu["vorraete"].get(r, 0) + menge
        produktion[r] = menge
    # Nahrungsverbrauch der Garnison: NACH der Ernte gebucht (der Ort isst, was er erntet),
    # je echte Spielspanne. KEIN Verbrauch bei leerer Spanne und bei leerem Ortslager-Heer.
    verbrauch = 0.0
    unterdeckung = 0.0
    if bis > ab:
        bedarf = tagesbedarf_nahrung(neu.get("einheiten") or {}) * (bis - ab) / 86400.0
        if bedarf > 0:
            vorher = float(neu["vorraete"].get("nahrung", 0.0) or 0.0)
            verbrauch = min(bedarf, max(0.0, vorher))
            unterdeckung = bedarf - verbrauch
            neu["vorraete"]["nahrung"] = vorher - verbrauch
    grenze = gebaeude_wirkung.bevoelkerungsgrenze([neu])
    zuwachs = gebaeude_wirkung.siedler_zuwachs_pro_stunde([neu], forschung) * (bis - ab) / 3600.0
    neu["bevoelkerung"] = min(grenze, neu["bevoelkerung"] + zuwachs)
    if bis > ab:
        zeile = {"ab": ab, "bis": bis, "mengen": produktion}
        if verbrauch > 0 or unterdeckung > 0:
            zeile["verbrauch"] = {"nahrung": verbrauch}
            zeile["unterdeckung"] = unterdeckung
        neu["produktionsjournal"].append(zeile)
    for schlange in neu["werkstaetten"].values():
        for ware, n in werkstatt.fertige_waren(schlange, bis).items():
            neu["waren"][ware] = neu["waren"].get(ware, 0) + n
            neu["fertigjournal"].append({"zeit": bis, "art": "ware", "name": ware})
    for a in neu["ausbildung"]:
        if not a["gebucht"] and a["ende"] <= bis:
            name = a["einheit"]
            neu["einheiten"][name] = neu["einheiten"].get(name, 0) + 1
            a["gebucht"] = True
            neu["fertigjournal"].append({"zeit": a["ende"], "art": "einheit", "name": name})
    return neu
```

```python
def siedlergrenze_je_siedlung(siedlung) -> int:
    """10 Siedler je Siedlung + 5 je Haus — und je Ausbaustufe weitere 5 (VORSCHLAG).

    Belegt ist Stufe 1: „+5 je Haus" (Handbuch Seite 11). Die Ausbaustufen des Hauses sind
    VORSCHLAG (Haus bis Stufe 4, je Stufe +5) — Quelle: data/gebaeude_wirkung.json,
    Abschnitt „haus_stufen", festgehalten nach der Vorgabe Daniel vom 05.10.2026
    („der Häuserausbau ist noch nicht klug entworfen"). Ein Haus ohne gespeicherte Stufe
    zählt wie Stufe 1, damit alte Spielstände unverändert bleiben.
    """
    r = regeln()["bevoelkerung"]
    haeuser = anzahl([siedlung], "haus")
    if haeuser <= 0:
        return int(r["grund_je_siedlung"])
    stufen = 0
    for feld, gebaeude in (getattr(siedlung, "bauten", {}) or {}).items():
        if _kennung(gebaeude) == "haus":
            stufen += max(1, stufe_von_feld(siedlung, feld))
    return int(r["grund_je_siedlung"]) + int(r["je_haus"]) * (stufen or haeuser)
```

```python
    return round(float(r["siedler_je_stunde"]) * len(liste) * faktor, 4)
```

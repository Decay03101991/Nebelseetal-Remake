Nebelseetal Remake

Einzelspieler · Windows · offline · kostenlos

Eine zersprungene Welt im Nebel: Du baust Siedlungen auf, forschst, rüstest aus und ziehst durch Portale – neben fünf Nachbarn, die selbst wirtschaften, bauen und rauben.

Windows 11, 64 Bit · Download rund 102 MB · kein Konto, kein Internet, kein Python

Was steckt drin

  • 6Welten im Limbus
  • 6Häuser mit Wappen
  • 5Nachbarn mit eigener Wirtschaft
  • 6Siedlungen je Reich
  • 4Auszeichnungen statt Sieg
  • 28Einheiten

Der Kreislauf: gründen → produzieren → forschen → ausrüsten → ausbilden → bewegen → kämpfen → punkten. Die vollständige Anleitung steht im Spiel beim Berater.

Was noch fehlt – ehrlich

  • Vorabversion. Kein fertiges Spiel, keine Kompatibilitätszusage.
  • Drei Kampfregeln fehlen: Fluchtformel, Beute-Reihenfolge, Mauerreparatur mit Bauzeit.
  • Sechs Welten sind noch nicht fertig umgestellt: im Code liegen 20 Limbus-Dimensionen, sechs sind belegt, 14 leer.
  • Diplomatie erst zur Hälfte: Gunst und Status sind da; Verträge, Rache und die drei Ereignisse sind entworfen, aber nicht eingebaut.
  • Handelspunkte werden noch nicht gebucht und stehen auf null.
  • Kein Ton, keine Musik.
  • Nur Windows 11, 64 Bit, auf einem Rechner getestet. Windows 10, ARM und kleine Displays sind ungeprüft. Eine macOS-Fassung gibt es nicht – sie müsste auf einem Mac gebaut und geprüft werden.
  • SmartScreen kann warnen, weil die EXE nicht signiert ist. Die Prüfsumme steht in SHA256SUMS.txt im ZIP.

So startest du

  1. Unter Releases das Paket Nebelseetal_Pre_Release_V_0.0.3.zip laden.
  2. Den Inhalt in einen neuen, leeren Ordner entpacken (kein geschützter Windows-Ordner).
  3. Nebelseetal_Pre_Release_V_0.0.3.exe per Doppelklick starten.
  4. Am Tor ein eigenes Passwort festlegen und notieren. Es bleibt auf deinem Rechner.
  5. Spielen. Der Spielstand liegt unter %LOCALAPPDATA%\Nebelseetal_Remake\Demo.
